# How the page is built

`index.html` at the repository root is the live page. It is generated by `build.py`.

- `build.py` holds all page text (project blocks, board tiles, detail views) and writes `../index.html`.
- `base.css` and `base.js` are the styles and the scroll/detail-view script it includes.
- Images and video live in `../assets/`.

To change the page: edit the text in `build.py`, run `python3 tools/build.py`, then commit and push. GitHub Pages republishes from the `main` branch.

Small text fixes can also be made directly in `index.html`, but they are overwritten the next time `build.py` runs, so make them in `build.py` too.
